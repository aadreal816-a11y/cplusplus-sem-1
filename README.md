# 🚀 C++ Programming Fundamentals (Semester 1)

Hi there! This repository contains all my laboratory exercises and assignments for the **Programming Fundamentals (C++)** course during my 1st Semester at **Politeknik Balik Pulau**.

## 📌 Topics Covered:
* **Basic Syntax:** Understanding `cout`, `cin`, header files, and data types.
* **Control Structures:** Implementing decision-making logic using `if`, `else if`, and `else`.
* **Loops:** Practicing repetitive structures with `for`, `while`, and `do-while` statements.

## 📂 File Structure
All source files (`.cpp`) are named directly after the specific lab activities and question numbers assigned by my lecturer for easy tracking and reference.
